# 文档总览

版本：v0.1（2026-10-31）

本文件是文档索引。新增或调整文档时同步更新这里，保证入口唯一。

## 1. 阅读顺序

| 顺序 | 读者 | 文档 |
|---|---|---|
| 1 | 所有人 | [README](../../README.md)：仓库定位、边界与接口一览 |
| 2 | 产品/开发 | [需求文档](../requirements/product-requirements.md)：做什么、验收、里程碑 |
| 3 | 开发 | [架构设计](../architecture/architecture-design.md)：怎么做、数据模型、检索与媒体 |

| 6 | Agent / 新人 | [项目结构](./project-structure.md)：目录与放置规则 |

## 2. 文档职责

| 文档 | 回答的问题 | 权威范围 |
|---|---|---|
| 需求文档 | 范围、功能 C1–C7、NFR、验收、里程碑、待冻结事项 | 云端做什么 |
| 架构设计 | 组件、部署、数据模型、检索管线、鉴权、媒体、安全、观测、ADR | 云端怎么做 |
| 对接清单 | 每个接口的请求/响应、边界、错误、验收用例 | 插件与云端的接口约定 |
| 项目规范 | 变更流程、API/安全/测试/文档/提交约定 | 团队执行标准 |
| 项目结构 | 现状与目标目录、放置规则、边界 | 代码组织 |
| 本文 | 文档索引、阅读顺序、维护规则 | 文档导航 |

插件仓库文档（`../dsh-plugin-trend-coach/docs/`）是接口消费方口径的最终来源；冲突时先改插件 PRD/架构，再同步本仓库。

## 3. 维护规则

- 新增文档：放入对应 `docs/<类别>/`，并在第 1、2 节登记。
- 接口变更：需求 → 架构 → 对接清单 → OpenAPI → 实现 → 测试，一次改齐。
- 里程碑或待冻结事项定稿后，更新对应文档的状态与结论，不留过期条目。
- 文档只写结论与依据，不复述代码实现细节；代码变化不必逐条回写文档，契约与不变量变化必须回写。
